**OBJECTIVE:**
This project focuses on performing exploratory and statistical analysis on an E-commerce dataset to extract actionable insight.

**TOOLS:**
MySQL

**PROCEDURES:**
-Downloaded E-commerce shipping dataset from Kaggle.
-Imported the table containing 10,999 rows of data into an existing database in MySQL.
-Renamed the first column to be more readable.
-Used SELECT, WHERE, ORDER BY, GROUP BY to perform exploratory data analysis.

**OBSERVATION:**
Warehouse F manages the highest volume of products with 592 total products shipped.
A total of 44,595 customer care calls were recorded across the entire dataset, indicating a significant voulume of customer support interractions.
